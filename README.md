# 🎧 Rock English Lab

Projeto pessoal para desenvolvimento de compreensão auditiva (*Listening*) e pronúncia (*Shadowing*) em inglês através de músicas de Rock e Metal. O foco principal é a assimilação de **Connected Speech** (junções de som na fala natural) e **Chunks** (blocos de sentido), eliminando a tradução mental.

---

## 🛠️ Tecnologias e Ferramentas

- **HTML5 / CSS3 / JavaScript:** Interface leve e local para controle refinado de reprodução de áudio.
- **Git & GitHub:** Versionamento e organização dos materiais de estudo.
- **Gemini AI:** Mapeamento fonético de letras, marcação de consoantes conectadas e extração de vocabulário contextual.
